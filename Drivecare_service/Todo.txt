Routes -

/user
POST - /login , sends OTP to user email (creates account if new)
POST - /verifyotp , verifies OTP and returns JWT token
POST - /user/logout , clears token cookie
PATCH - /user/:id , updates user account details (auth + isUser required)

/agent
POST - TODO: register agent
GET - TODO: get available agents
PATCH - TODO: assign agent to booking

/admin
POST - /service --> creates a new service (auth + isAdmin required)
GET - /service --> gets all services (auth required)
GET - /service/:id --> gets service by ID (auth required)
PUT - /service/:id --> update the service (auth + isAdmin required)
DELETE - /service/:id --> delete the service (auth + isAdmin required)

/vehicle (auth required)
POST - /vehicle --> add a vehicle
GET - /vehicle --> get user's vehicles
PUT - /vehicle/:id --> update vehicle
DELETE - /vehicle/:id --> delete vehicle

/address (auth required)
POST - /address --> add an address
GET - /address --> get user's addresses
PUT - /address/:id --> update address
DELETE - /address/:id --> delete address
